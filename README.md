# 季節の献立＆お買い物リスト

5週間分の献立を確認しながら、必要な食材を週ごとの買い物リストとして管理できるシンプルなWebアプリです。

献立から食材と数量を自動で集計し、「生協」と「スーパー」に振り分けて表示します。スマートフォンでの利用、印刷、ホーム画面への追加にも対応しています。

## 主な機能

- 夏・秋・冬の献立をボタンで切り替え
- 第1週〜第5週の献立をタブで切り替え
- 主菜・副菜から買い物リストを自動生成
- 同じ食材の必要量をまとめて集計
- 食材を「生協（月〜金の野菜）」と「スーパー（その他）」に自動分類
- 買い物済みの食材をチェックリストで管理
- `/` で区切られた候補料理を「切替」ボタンで選択
- 週単位のクリア、または全データのリセット
- 献立と買い物リストの印刷
- PWA対応（ホーム画面への追加、オフライン表示）

チェック状態と選択した献立は季節ごとにブラウザの `localStorage` に保存されるため、ページを閉じても同じ端末・ブラウザでは状態が引き継がれます。

## 使い方

1. 画面上部のタブから確認したい週を選びます。
2. 「今週の献立」で1週間分の主菜と副菜を確認します。
3. 「切替」が表示されている料理は、ボタンを押すと候補を変更できます。
4. 自動生成された買い物リストを見ながら、購入済みの食材にチェックを入れます。

第2週以降のスーパー用リストには、直前の週末（土・日）に必要な食材も含まれます。第1週では、前週として第4週または第5週を選択できます。

## ローカルで起動する

ビルドやパッケージのインストールは不要です。PWAやService Workerを正しく動作させるため、`index.html` を直接開くのではなくHTTPサーバー経由で起動してください。

Pythonを使う場合：

```bash
python3 -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000> を開きます。

> Tailwind CSSとWebフォントをCDNから読み込むため、初回表示時はインターネット接続が必要です。

## データを変更する

アプリが実際に表示に使用する献立と材料データは、現在 `index.html` 内の次の定数に埋め込まれています。

- `SUMMER_MENU_DATA`: 夏の5週間分の献立
- `AUTUMN_MENU_DATA`: 秋の5週間分の献立
- `WINTER_MENU_DATA`: 冬の5週間分の献立
- `INGREDIENTS`: 料理ごとの食材、数量、単位、分類
- `EXCLUDE_LIST`: 買い物リストへ表示しない常備品

リポジトリ内の `献立_夏.json`、`献立_秋.json` と `材料.json` はデータを確認・編集しやすくするための元データですが、ブラウザから直接読み込まれてはいません。内容を変更した場合は、`index.html` 内の対応する定数にも反映してください。

材料データの例：

```json
{
  "name": "玉ねぎ",
  "amount": 0.5,
  "unit": "個",
  "cat": "veg",
  "long": true
}
```

- `cat`: `veg`（野菜）、`meat`（肉）、`fish`（魚）、`other`（その他）
- `long`: 日持ちする野菜として扱う場合に `true`

献立名に複数候補を設定する場合は、`麻婆茄子/麻婆豆腐` のように `/` で区切ります。それぞれの料理名に対応する材料データも登録してください。

## PWAとしてインストールする

対応ブラウザでアプリを開き、ブラウザの「ホーム画面に追加」または「アプリをインストール」を選択します。インストール後は通常のアプリに近い形で起動できます。

更新が反映されにくい場合は、Service Workerのキャッシュ名（`sw.js` の `CACHE_NAME`）を変更してから再読み込みしてください。

## ファイル構成

```text
.
├── index.html                 # メインアプリ（画面・ロジック・データ）
├── 献立_夏.json              # 夏の献立の元データ
├── 献立_秋.json              # 秋の献立の元データ
├── 献立_冬.json              # 冬の献立の元データ
├── 材料.json                  # 材料の元データ
├── 献立カレンダー.html        # 季節切り替え対応の印刷用カレンダー
├── manifest.webmanifest       # PWA設定
├── sw.js                      # オフラインキャッシュ
├── icon-192.png               # アプリアイコン
└── icon-512.png               # アプリアイコン
```

## 技術構成

- HTML / CSS / Vanilla JavaScript
- Tailwind CSS（CDN）
- Web Storage API（`localStorage`）
- Web App Manifest / Service Worker

サーバー処理やデータベースは使用しておらず、すべてブラウザ内で動作します。
